Seriousness criteria

An event is serious if it meets any of these (ICH E2A). Seriousness is not the same as severity.

ℹ️Severity vs seriousness. A “severe” headache is intense but usually not serious. A “mild” event that leads to hospital admission is serious. Regulatory timelines follow seriousness.
